# Mesh Grid Studio: аудит интерфейса и удобства

Дата: 22.09.2026. База: `43e66c39e4a2283f331742212adff7128d64f74a`
(научно исправленный проект, draft PR #2). UI-изменения не влиты в `main`.

## Объём проверки

Проверены контроллер Tk, модель рабочего состояния, все пользовательские
действия сохранения/открытия/экспорта, переключение размерности, обработчики
мыши и клавиш, фоновые расчёты, сравнение, диагностические сообщения,
существующие численные регрессии и согласованность научных артефактов.
Это конкретный набор воспроизводимых проверок, не доказательство отсутствия
всех возможных ошибок.

Численные `mesh_methods.py`, `mesh_methods_3d.py`, `mesh_geometry_3d.py` и
`mesh_gui_model.py` не изменялись. Новые возможности меняют интерфейс,
проверки входных проектов, управление состоянием и визуализацию.

## Подтверждённые проблемы и исправления

| Проблема | Исправление |
|---|---|
| Основные действия скрывались в длинной прокрутке | Закреплённые «Построить», «Сравнить», «Сбросить»; постоянная файловая панель |
| Смешанные настройки затрудняли поиск | Вкладки «Сетка», «Параметры», «Вид / правка» с независимой прокруткой |
| На небольшом/масштабированном экране обрезались кнопки | Панель переносится на две строки; проверены 960×640, 1024×700 и Tk scaling=2.0 |
| Подпись пресета при запуске не всегда соответствовала геометрии | Восстановление самой геометрии из проверенного пресета |
| Переключение 2D/3D теряло рабочее состояние | Раздельные состояния с параметрами, моделью, результатом, историей и путём проекта в рамках сеанса |
| Открытие проекта другой размерности могло затереть несохранённую область | Явное подтверждение замены целевой области |
| Не было отмены геометрических правок | Ctrl+Z/Ctrl+Y, до 30 действий для 2D |
| Параметры менялись, а старая сетка выглядела актуальной | Явное предупреждение; метрики и отчёт сохраняют параметры показанного результата |
| Ручная правка сохраняла невязку старого решателя | Сходимость и невязка аннулируются, ручной результат обозначается явно |
| Сравнение при выбранном линейном методе не учитывало все параметры нелинейных методов | Снимок всех параметров до запуска сравнения |
| «Победитель» выбирался среди некорректных/несошедшихся результатов, равенства игнорировались | Метки только среди минимум двух сопоставимых результатов; равенства отмечаются вместе |
| Число итераций/время выдавались за «лучший метод» | Для этих строк нет научного ранжирования |
| Ошибка одного метода стирала остальные | Независимые результаты и ошибки трёх методов |
| Устаревшее сравнение могло примениться к другой геометрии | Проверка версии состояния и размерности; настройки выбранного результата синхронизируются |
| Сохранение могло испортить существующий файл при сбое записи | Временный файл в том же каталоге, fsync, os.replace; тест отказа замены |
| Некорректный проект частично изменял состояние | Проверка размера файла, схемы, числовых значений, границ и общих углов до открытия |
| Набранное огромное число узлов могло попасть в preview | Диапазон проверяется до выделения массива |
| Плотный шар молча пересчитывался на меньшей сетке | Ограничение 9 узлов явно показывается; недопустимый ручной ввод отклоняется |
| Ошибка нового расчёта оставляла старую «успешную» сетку | Старый результат снимается; ошибка и traceback доступны в диагностике |
| Правая кнопка мыши накапливала уже применённый zoom | Используется только приращение положения мыши |
| Упрощённый 3D-каркас мог пропускать крайнюю плоскость | Обе крайние плоскости всегда включаются; CSV содержит все узлы |
| Прозрачность линий соответствовала старому ракурсу | Глубинная сортировка и прозрачность пересчитываются при смене камеры |
| Белая поверхностная сетка заглушала цвета направлений | Отдельный светлый контур из 12 рёбер, цветной объёмный каркас и более крупный начальный вид |
| При наведении текст кнопки становился почти белым на белом | Явные активные/нажатые состояния; тест контраста текста ≥4.5 |
| Закрытие с ожидающими TkAgg callback давало ошибки Tcl | Отмена таймеров через создавшие их виджеты; worker не обращается к Tk |

## Как пользоваться

На вкладке «Сетка» выбрать 2D/3D, область, размеры и метод.
Параметры итераций, допуска, μ и балансировки находятся во второй вкладке.
F5 или Ctrl+Enter запускает выбранный расчёт. «Сравнить все методы»
использует один снимок геометрии и параметров; результаты можно показать
в основной сцене, скопировать или сохранить в JSON.

В 2D доступно редактирование мышью и история изменений. В 3D левая кнопка
вращает сцену, правая кнопка и колесо меняют масштаб. Во вкладке вида есть
готовые ракурсы, автоповорот, упрощённый каркас и подгонка вида.

Ctrl+O открывает проект, Ctrl+S сохраняет в текущий файл, Ctrl+Shift+S -
в новый файл. CSV/PNG/JSON-отчёт доступны на верхней панели. Сдвиг разделителя
между графиком и таблицей меняет их размер.

## Проверки и доказательства

В проекте 120 тестов: 63 прежние научные/модельные регрессии и 57 новых
тестов I/O и пользовательских сценариев (часть на настоящих виджетах Tk).
Актуальный результат запуска записывается в `output/audit/tests.txt` и
`output/audit/verification.json`; в JSON отдельно указаны выполненные и
пропущенные тесты. Успешность нельзя выводить только из этого описания.

Команды:

```text
python -m unittest discover -v
# Linux без рабочего стола:
xvfb-run -a python -m unittest discover -v
xvfb-run -a python audit_reproduce.py
python verify_artifacts.py
```

`audit_reproduce.py` без `--full` сохраняет исходную расчётную серию.
Повторяются проверки аналитических градиентов и контрольные расчёты.
`verify_artifacts.py` дополнительно пересчитывает метрики 12 сохранённых
3D-сеток и проверяет CSV/таблицы/хеши/архив. Это не новая серия экспериментов
по научной новизне, разрешению сетки или чувствительности к μ.

`.github/workflows/windows-ui-preview.yml` собирает отдельный unsigned
Windows preview и выполняет тесты, self-test решателей и smoke-test
упакованного приложения. Факт успешной Windows-сборки подтверждается
именно завершённым workflow и его логами, не наличием YAML-файла.

Иллюстрации `docs/ui-usability-*.png` созданы `capture_ui.py` на реальных
Tk-окнах; это не дизайн-макеты. Старые иллюстрации научной статьи сохранены
как архивные.

## Границы и что ещё не сделано

- Рабочие пользовательские геометрии и результаты переживают переключение
  2D/3D только внутри сеанса. После выхода без сохранения они не восстанавливаются.
- Проект хранит границу/пресет и параметры, а не вычисленную сетку и не
  ручные перемещения внутренних узлов. Их нужно сохранять в CSV.
- Undo/redo относится к геометрическим правкам 2D, а не к каждому полю настроек.
- Нет прерывания текущего решателя с сохранением его промежуточного состояния.
  Окно остаётся отзывчивым; закрытие во время работы требует подтверждения.
- 27-точечная проверка не доказывает положительный якобиан между точками
  или глобальную взаимную однозначность. UI не должен трактоваться как сертификат.
- Глубинная прозрачность линий - визуальная эвристика, не точный алгоритм
  скрытых поверхностей. Упрощение не влияет на расчёт или экспорт.
- Проверка Tk scaling=2.0 не заменяет ручные проверки всех Windows DPI,
  сочетаний мониторов и драйверов на пользовательском ПК.
- Preview не является опубликованным релизом, не подписан сертификатом
  и не отменяет нерешённых вопросов научной новизны из SCIENTIFIC_AUDIT.md.
